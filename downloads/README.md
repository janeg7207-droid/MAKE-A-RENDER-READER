# ZIP downloads

The full program ZIP contains the separate experimental v1.0.2 build. It uses Git LFS; use the direct download link in the repository README, or install Git LFS before cloning.

The small update ZIP requires a separate copy of the original GorillaStudio v1.0.2 folder. Keep its engine, data and plugin files. It does not apply to v1.0.

The source ZIP contains the helper, patcher and tests. The checksum file lists SHA-256 values for all three ZIPs.

This is an experimental build. The Windows GUI smoke test and complete game-backed rendering remain unverified; details are in the main README and the ZIP's TEST_RESULTS.json.
